## 🚀 Stack Tecnológica

### ⚙️ Backend
- Node.js
- Express 5
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT (Autenticação)
- Bcrypt (Hash de senha)
- Multer (Upload de arquivos)
- Cloudinary (Armazenamento de imagens)
- Zod (Validação)
- Dotenv
- CORS

### 🖥️ Frontend
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Radix UI
- Lucide React
- Class Variance Authority

---
